# 日本語漢字ドリル生成（日语汉字字帖生成器）

完全离线的**日语汉字/假名描红字帖生成程序**，单文件 HTML，双击即可在浏览器运行（无需联网、无需安装）。专为日本语言学校课堂听写与书写练习设计。

## 在线使用

本仓库已启用 GitHub Pages，打开 **https://kanryo33.github.io/kanji/** 即可直接在浏览器中使用（课堂投影推荐）。

## 功能

- 界面**默认日语**，右上角可切换为中文（选择会被记住）
- 输入任意日语汉字/假名，或一键填入五十音（平假名/片假名，每个假名自动独立成行）
- **教材页码快速填入**：输入框上方选择教材（漢字たまご 初級 / 初中級 / 中級）并输入页码，自动填入该页汉字与词汇（每词一行、同页去重）
- 7 种方格（田字格/米字格/回宫格/九宫格等）、**日式笔顺**逐笔描红（当前笔红色）、首字高亮
- 排版模式：单字 / 词组 / 短文；支持插入空行/空列、描红数量、描红颜色
- 调整方格大小、行间距、页边距、字体、字体粗细、整体缩放（格子与字同步）、上下偏移
- **300 DPI 高清 PNG 导出**（A4 约 2474×3496 像素，矢量重绘保证笔画清晰）
- **打印**同样按 300 DPI 渲染、A4 自动分页、自动加页码；每页顶部固定 クラス/氏名 填写栏
- 移除注音显示，保持纯汉字/假名，适合听写与书写练习

## 字体

- 默认 **HGP教科書体**（Windows 预装系统字体，不内嵌，无再分发问题）；其他电脑没有时自动回退到内置 **Klee One 楷書体**
- 可选：Klee One 楷書体（内置）、MS Mincho、Yu Mincho、Meiryo、Yu Gothic
